# Perpetual market universe

이 목록은 2026-09-30 10:50–11:09 UTC에 Bybit `turnover24h`, Hyperliquid
`dayNtlVlm`, Aster `quoteVolume`, GRVT의 `buy_volume_24h_q +
sell_volume_24h_q`를 USD/USDT 거래대금(notional turnover)으로 합산한 뒤,
토큰화 주식·레버리지 ETF·원자재를 제외한 상위 50개 crypto perpetual이다.
24시간 거래대금은 계속 변하므로 영구적인 순위가 아니다.

거래 수량을 단순 합산하지 않는다. `PUMPFUN/PUMP`, `1000PEPE/kPEPE`,
`1000BONK/kBONK`처럼 거래소마다 이름이나 계약 배수가 다른 동일 기초자산은
하나로 정규화한 뒤 거래대금을 합산한다.

GRVT는 active crypto perpetual 각각의 derived ticker를 조회해 순위 산출에도
포함했다. 표의 `—`는 조사 시점에 해당 거래소에서 지원되지 않았다는 뜻이다.

코드의 canonical symbol은 첫 번째 열의 자산명이다. 거래소별 실제 심볼은
`src/bbo_probe/markets.py`에서 변환한다.

```bash
make markets
make collect VENUES="bybit aster" SYMBOLS="BTC ETH SOL" DURATION=300
make collect-top50 VENUES="bybit hyperliquid aster grvt" DURATION=300
```

명시한 조합이 지원되지 않으면 `collect`는 오류를 반환한다. `collect-top50`은
지원하지 않는 조합을 stderr에 표시하고 나머지만 수집한다.
